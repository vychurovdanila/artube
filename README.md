# ARTUBE — Платформа современного искусства и декора

ARTUBE — это независимый коммерческий продукт, созданный в партнерстве с AI-студией Makefab. Это браузерный маркетплейс (B2B/B2C) для современных художников, скульпторов и мебельщиков, а также умный инструмент подбора декора для архитекторов и дизайнеров интерьера.

## 🎯 Бизнес-суть и ценность
Платформа решает проблему визуализации искусства в интерьере.
1. **Для авторов:** Красивая упаковка работ (генерация премиальных карточек с ИИ-рендерами в интерьерах), продажи, аудитория.
2. **Для дизайнеров:** Быстрый поиск релевантного декора (по цвету, стилю, цене) и удобный инструмент WebAR для «примерки» картин на стенах клиента прямо с телефона.
3. **Монетизация:** Кэшбеки дизайнерам за продажи, платные услуги по 3D-подготовке, комиссия с продаж.

## 🏗️ Ключевая логика (Онбординг)
При добавлении работы автор выбирает тип:
1. **Картина (Painting):** Загружает фото и размеры. Платформа автоматически генерирует 3D-холст (базовый GLB + текстура) для AR. Бесплатно.
2. **Скульптура (Sculpture):** Загружает фото. Платформа рассчитывает стоимость создания 3D-модели (платная услуга).
3. **Готовая 3D-модель:** Загружает свой файл (GLB). Платформа рассчитывает стоимость оптимизации и AR-форматирования (конвертация в USDZ для Apple).

*Все работы проходят строгую премодерацию (ИИ + человек) для отсеивания нерелевантного «мусора».*

## 🛠️ Технологический стек
*   **Frontend:** React 19, Vite, TypeScript, Tailwind CSS (v3.4).
*   **Backend:** Python 3.12+, FastAPI, SQLAlchemy (ORM), SQLite (на старте).
*   **3D/AR:** Google `<model-viewer>` (WebAR, поддержка iOS/Android).
*   **AI:** Внешние бесплатные API для генерации интерьеров по шаблонам (Stable Diffusion / Hugging Face).

🚀 Инструкция по локальному запуску
1. Запуск Frontend (React)
bash
cd frontend
npm install
npm run dev
Фронтенд будет доступен по адресу: http://localhost:5173

2. Запуск Backend (Python FastAPI)
Убедитесь, что у вас установлен Python 3.12+.

bash
# Перейти в папку бэкенда
cd backend

# Создать виртуальное окружение (один раз)
python -m venv venv

# Установить зависимости (один раз)
.\venv\Scripts\python.exe -m pip install -r requirements.txt

# Запустить сервер
.\venv\Scripts\python.exe -m uvicorn app.main:app --reload
API будет доступно по адресу: http://127.0.0.1:8000
Документация API (Swagger): http://127.0.0.1:8000/docs
