# BRIEF — ARTUBE
**Дата:** 2026-11-01 (v3)
**Заказчик:** Независимый коммерческий продукт (не связан с другими проектами Makefab)
**Ответственный:** Данила (CEO)

## 1. Задача
Создать платформу-витрину (маркетплейс + медиа-хаб) для современных художников, скульпторов и мебельщиков. Платформа помогает авторам создавать премиальные карточки товаров с ИИ-визуализацией и дает архитекторам/дизайнерам удобный поиск декора для проектов. ARTUBE полностью независим от Artester, но предоставляет платные услуги по 3D-подготовке контента.

## 2. Аудитория
- **Творцы:** Загружают работы. Хотят продавать, получать качественную визуализацию и аудиторию.
- **Профессионалы:** Ищут декор по цвету, стилю, цене. Нужен быстрый способ встроить предмет в проект (3D/AR).
- **B2C Клиенты:** Выбирают работы, примеряют в AR у себя дома.

## 3. Логика онбординга и услуг (Ключевое!)
При загрузке работы автор выбирает её тип:
1. **Картина:** Указывает размеры. Платформа автоматически генерирует 3D-холст с текстурой картины. Оплата не требуется.
2. **Скульптура:** Загружает фотографии. Платформа рассчитывает стоимость создания 3D-модели (услуга платформы) и показывает кнопку заказа.
3. **Готовая 3D-модель:** Загружает свой файл. Платформа рассчитывает стоимость оптимизации и AR-форматирования (конвертация в GLB/USDZ).

## 4. Что входит в скоуп (MVP)
- Каталог работ (фильтрация по стилю, гамме, типу, цене).
- Личный кабинет автора (загрузка, заполнение брифа, генерация 3D-холста или заказ услуги).
- **ИИ-генератор интерьеров:** На основе брифа работы и выбранного шаблона (например, "Лофт", "Скандинавский") формируется промт для ИИ, который генерирует уникальный рендер комнаты с работой автора.
- WebAR просмотр (примерка на стене через `<model-viewer>`).
- **Медиа-раздел:** Видео-интервью, статьи, бэкстейджи.

## 5. Что НЕ входит в скоуп (на данном этапе)
- Автоматический рендер 3D со стороны ARTUBE (выполняется как платная услуга, возможно, вручную или через сторонние API).
- Генерация капсульных коллекций с брендами.
- Индивидуальные мастер-классы.

## 6. Критерии приёмки (MVP)
- [ ] При загрузке автор выбирает тип (картина/скульптура/3D) и видит разные сценарии.
- [ ] Для картин 3D-холст генерируется автоматически по размерам.
- [ ] Для скульптур и 3D-моделей работает калькулятор стоимости.
- [ ] ИИ генерирует уникальный рендер интерьера на основе брифа.
- [ ] Работает WebAR примерка.
- [ ] Есть раздел "Медиа".

## 7. Технологии
- **Фронтенд:** React (Vite) + Tailwind CSS.
- **Бэкенд:** Python (FastAPI).
- **3D-форматы:** GLB (веб), USDZ (iOS AR).
- **ИИ-генерация:** API внешних моделей по шаблонам.
- **Генерация 3D-холстов:** Простая библиотека на бэкенде (например, Three.js / Python-обертки).

## 8. Риски
- Логика расчета стоимости услуг (нужен четкий прайс и калькулятор).
- Задержки генерации интерьеров через ИИ (нужен UX с индикатором загрузки).
